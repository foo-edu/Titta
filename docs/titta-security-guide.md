# Titta！ セキュリティ取扱説明書

**バージョン：v2.1 / 2026年9月**

**対象：学校のICT担当者・管理職・教職員・保護者**

---

## はじめに

この説明書は、「Titta！」を学校現場で安全に使用するために必要なセキュリティ情報をまとめたものです。技術的な知識がなくても理解できるよう、平易な言葉で説明しています。

> 「Titta（ティッタ）」はスウェーデン語で「見る」を意味します。

---

## 第1章　このアプリで「何が起きているか」を知る

### アプリを開くとき、何が起きているか

ブラウザでURLにアクセスすると、以下のことが起きています。

```
① アプリの画面データがGitHubのサーバーから届く
　（HTMLファイルをダウンロードするイメージ）

② タスクデータがGoogleのサーバー（Firebase）から届く

③ 画面が表示される
```

操作するたびに、変更内容がGoogleのサーバーに送信・保存されます。これによって複数の端末でデータが同期されます。

---

### 「データ」とは何か

このアプリが扱うデータは**タスクの内容だけ**です。

**送信・保存されるもの**
- タスクのタイトル（例：「数学の宿題」）
- 締切日
- 重さ（大・中・小）
- メモ
- 完了しているかどうか

**一切送信・保存されないもの**
- 氏名・生年月日・学年・クラス
- メールアドレス・電話番号
- 学校名・住所
- 端末の情報・位置情報
- パスワード（そもそも存在しない）

> **ポイント：このアプリは「誰のタスクか」を知りません。タスクの内容しか知らないアプリです。**

## 第2章　URLが「カギ」になる仕組み

### 個人IDとは

このアプリはログインの代わりに、**ランダムに生成された個人ID（16文字）**でデータを管理します。

```
https://foo-edu.github.io/Titta/#p_k4m9x2q7r3n8v5c1
                                         ↑
                          これが個人ID（ランダムな16文字）
```

組み合わせは約8×10^24通り（8兆の1兆倍）です。仮に1秒間に100万回試しても、すべて試し終えるには宇宙の年齢より長い時間がかかります。

初めてアプリを開いたとき、この個人IDが自動的に作られてURLに埋め込まれます。以降、このURLがデータへのアクセスキーになります。

### わかりやすい例え

> **自分専用の鍵付き日記帳のようなものです。**
> 鍵の番号を知っている人だけが開けられます。鍵番号を誰かに教えない限り、他人には開けられません。

### URLを失うとどうなるか

URLを失う（ブックマークを消す・URLをメモしていない）と、自分のデータにアクセスできなくなります。データ自体はGoogleのサーバーに残りますが、取り出す手段がありません。

> **→ URLは必ずブックマークするよう指導してください。**

## 第3章　Googleのサーバー（Firebase）について

### Firebaseとは

Firebaseは**Googleが運営するクラウドデータサービス**です。世界中の企業・学校・医療機関などで広く使われています。

### Googleはデータを何に使うか

FirebaseはGoogleのサービスですが、**Googleがユーザーのタスクデータを広告や分析に使うことはありません**。FirebaseはGoogleとは独立したデータ保管庫として機能します（Googleの利用規約で定められています）。

### データはどこに保存されるか

このアプリのデータはGoogleのデータセンター（アジア東南部）に保存されています。

### 通信は安全か

アプリとGoogleのサーバー間の通信はすべて**HTTPS（暗号化通信）**で保護されています。これはインターネットバンキングやオンラインショッピングと同じ水準の暗号化です。通信の途中で第三者に内容を盗み見られることはありません。

### Googleのセキュリティ水準

Googleのサーバーは以下の国際セキュリティ基準に準拠しています。

| 認証 | 内容 |
|---|---|
| ISO/IEC 27001 | 情報セキュリティ管理の国際標準 |
| SOC 2 | クラウドサービスの安全性評価基準 |
| GDPR対応 | EU一般データ保護規則に準拠 |

## 第4章　想定されるリスクと対策

### リスク①　URLを他人に知られる

| 項目 | 内容 |
|---|---|
| **何が起きるか** | 他人が自分のタスクを見る・書き換える・削除できる |
| **どんな時に起きるか** | URLを友人に送る・スクリーンショットを共有する・画面を見られるなど |
| **深刻度** | 中（タスクデータの改ざん・消去が起きる可能性） |
| **個人情報漏洩の危険** | 低（氏名等の個人情報はデータに含まれない） |
| **対策** | URLを他人に教えない指導を徹底する |
| **もし起きたら** | 新しいURLで使い始める（旧データは引き継げないが数分で再開可能） |

---

### リスク②　外部サービス（Google）へのデータ送信

| 項目 | 内容 |
|---|---|
| **何が起きるか** | タスクデータがGoogleのサーバーに送信・保存される |
| **どんな時に起きるか** | アプリを使用しているとき常時 |
| **深刻度** | 低（個人情報を含まないデータのため） |
| **対策** | 学校のICTポリシーで外部サービス利用が許可されているか確認する |
| **ポリシーに抵触する場合** | 本アプリの導入を見送ってください。同期を個別に無効化する設定は用意していません |

---

### リスク③　端末の紛失・他者への貸し出し

| 項目 | 内容 |
|---|---|
| **何が起きるか** | ブラウザの履歴・ブックマークからURLを見られる |
| **どんな時に起きるか** | 端末を他者と共有・貸し出す場合 |
| **深刻度** | 低（1人1台端末なら発生しない） |
| **対策** | 1人1台端末の運用を徹底する |

---

### リスク④　他人のURLへの不正アクセス（いたずら）

| 項目 | 内容 |
|---|---|
| **何が起きるか** | 他の生徒のURLを入手して、タスクを書き換える・削除する |
| **どんな時に起きるか** | 生徒同士でURLを共有・のぞき見するなど |
| **深刻度** | 中（いじめ・嫌がらせに発展する可能性） |
| **対策** | URLの取り扱いについてモラル教育を行う |
| **もし起きたら** | 被害を受けた生徒は新URLで即座に再開可能。必要に応じ開発者がFirebaseからデータを削除 |

---

### リスク⑤　第三者によるURLの推測

| 項目 | 内容 |
|---|---|
| **何が起きるか** | 悪意ある第三者がURLを推測してデータにアクセスする |
| **深刻度** | 非常に低 |
| **理由** | 個人IDは16文字のランダムな英数字。約8×10^24通りあり、総当たりは現実的でない |
| **補足** | 「全ユーザーの一覧」を取得することはできません。IDを知っている1件しか読めない設定です |

---

### リスク⑥　細工されたURLによる不正な動作

| 項目 | 内容 |
|---|---|
| **何が起きるか** | 悪意ある第三者が細工したURLを生徒に踏ませ、ブラウザ上で不正な動作をさせる |
| **どんな時に起きるか** | SNSやメッセージで送られたリンクを不用意に開いた場合 |
| **深刻度** | 非常に低（対策済み） |
| **対策** | アプリは受け取ったデータを画面に出す前にすべて検証し、不正な内容を除去します |
| **指導事項** | 知らない人から送られた「Titta！」のリンクは開かないよう伝えてください |

---

### リスク⑦　機械的な大量書き込みによるサービス停止

| 項目 | 内容 |
|---|---|
| **何が起きるか** | 悪意ある第三者が自動プログラムで大量のデータを書き込み、無料枠を使い切らせる |
| **どんな時に起きるか** | アプリが広く公開され、悪意ある第三者の目に触れた場合 |
| **深刻度** | 低（対策済み。ただし完全には防げない） |
| **影響** | **データが盗まれることはありません。**データベースが一時的に応答しなくなり、生徒がタスクを開けなくなります |
| **対策** | 1回に保存できるデータ量に上限を設定済み。開発者が使用量を監視しています |
| **もし起きたら** | 開発者が不正データを削除し、必要に応じて自動書き込みを遮断する仕組み（App Check）を有効化します。生徒側の操作は変わりません |
| **費用面** | 無料プランのため、**想定外の請求が発生することはありません** |

## 第7章　トラブル発生時の対応

**個別のデータ復元・削除の依頼はお受けしていません。** 学校内で対応できる方法を示します。

| トラブル | 対応方法 |
|---|---|
| URLを他人に教えてしまった | ブラウザのデータを消して開き直すと新しいURLが発行されます。以後はそちらを使ってください（旧データは引き継がれません） |
| タスクを勝手に消された・書き換えられた | 上と同じ手順で新しいURLに移ってください |
| データが消えた | **復元する手段はありません。** 重要な予定は手帳等にも控えてください |
| 不適切な内容が書き込まれた | そのURLの使用をやめ、新しいURLに移ってください |
| 同期されない（複数端末で内容が違う） | 無料枠超過で同期が一時停止している可能性があります。時間をおいてお試しください。各端末内のデータは残っています |
| アプリが開かない | 通信環境をご確認のうえ、時間をおいてお試しください |

## 第8章　生徒への指導事項（推奨）

以下の内容を生徒に伝えることを推奨します。

### 必ず伝えること

1. **URLは自分だけの鍵です。他人に教えてはいけません。**
2. **URLは必ずブックマークしてください。失うと復元できません。**
3. **タスクに氏名・住所・電話番号などの個人情報を入力しないでください。**
4. **知らない人から送られた「Titta！」のリンクは開かないでください。**

### できれば伝えること

5. 他人のURLを使ってタスクを書き換えることは、器物損壊や不正アクセスにあたる可能性があります。
6. スクリーンショットをSNSに投稿すると、URLが見えてしまう場合があります。**投稿前にアドレスバーが写っていないか確認してください。**

## 第9章　個人情報の取り扱い

### 収集しない情報

本アプリは、**氏名・生年月日・学年・クラス・メールアドレス・電話番号・学校名・住所・位置情報を一切収集しません。** アカウント登録もありません。

### 保存される情報

保存されるのはタスクの内容（タイトル・締切日・重さ・メモ・完了状態）のみです。これらは自動生成されたランダムな個人IDと結び付けて保存されますが、**そのIDから利用者個人を特定することはできません。**

### 第三者提供

収集した情報を第三者に販売・提供することはありません。アプリ内に広告はなく、アクセス解析ツールも導入していません。

### 保存先と保存期間

データはGoogleのFirebase（アジア東南部のデータセンター）に保存されます。保存期間の定めはなく、明示的な削除機能もありません。**利用をやめる場合は、URLを破棄してください。** URLを失えば、そのデータには誰もアクセスできなくなります。

### 生徒への指導について

上記のとおり個人情報は収集しませんが、**生徒がタスクのタイトルやメモに自分で個人情報を書き込むことは技術的に可能です。** 氏名・住所・電話番号などを入力しないよう、あらかじめご指導ください。
