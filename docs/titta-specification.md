# Titta！ 仕様書

**バージョン：v2.1 / 2026年9月**

**対象：学校のICT担当者・管理職・教職員**

**公開URL：`https://foo-edu.github.io/Titta/`**

---

## 1. 概要

Titta！は、**インストール不要・ログイン不要**で使えるブラウザ型タスク管理アプリです。カレンダーで締切と準備期間を視覚的に管理できます。

---

## 2. 動作環境

| 項目 | 内容 |
|---|---|
| 動作場所 | ブラウザ（Chrome / Safari / Edge 等） |
| インストール | 不要 |
| ログイン | 不要 |
| 対応端末 | PC・タブレット・スマホ（レスポンシブ対応） |
| オフライン | 一部利用可（初回アクセス後） |
| 料金 | 無料 |

## 3. 主な機能

### 3-1. タスク管理

| 機能 | 内容 |
|---|---|
| タスク追加 | タイトル・締切日・重さ・メモを入力して追加 |
| タスク編集 | ⋮ボタンから編集モーダルを表示 |
| タスク削除 | タスク詳細画面から削除 |
| 完了チェック | チェックボックスで当日の完了をマーク。完了タスクは薄く表示 |
| 重さ設定 | 大・中・小の3段階。準備期間の長さに対応 |
| メモ | タスクごとに任意のメモを記入可能 |

### 3-2. カレンダー表示

| 機能 | 内容 |
|---|---|
| 月間カレンダー | 当月のカレンダーを表示。前後月の移動可能 |
| 準備期間バー | 締切日から逆算した準備期間を色付きバーで表示 |
| 色分け | 大＝パステルレッド、中＝パステルイエロー、小＝パステルグリーン |
| 今日ハイライト | 今日の日付を淡い背景と上部の罫線で強調表示 |
| 日付タップ | カレンダーの日付をタップしてタスクを追加 |
| **予定の移動** | **バーをドラッグして別の日に移動。スマホは長押ししてから移動** |

### 3-2-1. 予定の移動（ドラッグ＆ドロップ）

いったん登録したタスクは、カレンダー上のバーをつかんで別の日に動かせます。編集画面を開き直す必要はありません。

| 操作 | 方法 |
|---|---|
| パソコン | バーをつかんでそのままドラッグ |
| スマホ・タブレット | バーを長押ししてから指を動かす |
| 取り消し | ドロップ前に Esc キー（パソコン） |

- つかんだ日から落とした日までの差分だけ、準備期間ごとタスク全体がずれます
- 移動後の準備期間から外れた完了チェックは自動的に外れます
- スマホで長押しせずに動かした場合は、月をめくるスワイプや画面スクロールとして扱われます（誤操作で予定が動くことはありません）

### 3-8. デザイン方針

スウェーデン／北欧のデザイン思想にならい、装飾を足すのではなく削る方向で設計しています。

| 項目 | 方針 |
|---|---|
| 配色 | 生成りの紙のような暖色ニュートラルを下地に、アクセントはくすんだ北欧ブルー |
| 作業期間の色 | 大・中・小は淡いパステルの赤・黄・緑。文字は濃いインクを重ねて可読性を確保 |
| 形 | 角丸をほぼ使わず直線的に。影は使わず、髪の毛のように細い罫線で区切る |
| 文字 | Inter を基本とし、見出しは大文字＋字間を広めに |
| アイコン | 絵文字は使わず、単線のSVGアイコンに統一 |
| ロゴ | 3本の縦棒（大・中・小の準備期間）を抽象化した幾何学的なマーク |

絵文字を排したのは、装飾性を抑える目的に加え、端末やOSによって見え方が変わらないようにするためです。

準備期間のバーは淡いパステルですが、上に載る文字は白ではなく濃い同系色にしています。パステル地に白文字だと読めなくなるためで、**すべての文字と背景の組み合わせがWCAG AA基準（コントラスト比4.5:1）を満たすことを実測で確認しています**（実測値5.75〜8.02）。

## 4. データの仕組み

### 4-1. 個人IDとURL

初回アクセス時に**ランダムな個人ID（16文字）**が自動生成され、URLのハッシュ（`#`以降）に埋め込まれます。

```
例：https://foo-edu.github.io/Titta/#p_k4m9x2q7r3n8v5c1
```

この個人IDがデータの「鍵」です。同じURLを開けば同じタスクデータにアクセスできます。

IDは暗号用の乱数生成器（`crypto.getRandomValues`）で作られ、使う文字は数字と小文字アルファベットの36種類です。組み合わせは約8×10^24通り（8兆の1兆倍）あります。

なお個人IDは `?` ではなく `#`（ハッシュ）に置いています。ハッシュはブラウザからサーバーへ送信されないため、GitHubやGoogleのアクセスログに個人IDが記録されません。

### 4-2. データ保存の流れ

```
操作する
  ↓
ブラウザ内（ローカルストレージ）に保存
  ↓
Firebase（Googleのクラウド）に同期
  ↓
同じURLを開いている他の端末にリアルタイム反映
```

### 4-3. 保存されるデータ一覧

| データ | 保存場所 |
|---|---|
| タスク一覧（タイトル・締切・重さ・メモ・完了状態） | ローカル＋Firebase |
| 設定（準備日数・言語） | ローカルのみ |
| 個人ID | ローカルのみ |
| チュートリアル完了フラグ | ローカルのみ |

**保存されない情報：氏名・学年・クラス・メールアドレス・位置情報・端末情報**

## 5. セキュリティ仕様

### 5-1. 通信の暗号化
すべての通信はHTTPS（TLS暗号化）を使用しています。第三者による盗聴はできません。

### 5-2. 認証方式
ログイン認証は使用しません。個人IDを含むURLが「パスワード」の役割を果たします。

### 5-3. Firebaseのアクセス制御
個人IDのパスに対応するデータは、そのIDを知っている人なら読み書きできます。IDはランダムな16文字のため、第三者が推測することは事実上不可能です。

Firebaseのセキュリティルールを設定済みで、次の制限がかかっています。

| 制限 | 内容 |
|---|---|
| ID形式の検証 | 正しい形式の個人IDのパス以外は読み書きを拒否 |
| 一覧取得の禁止 | 「全ユーザーのデータ一覧」は取得できない（IDを知っている1件のみ） |
| データ形式の検証 | 締切日・重さなどが正しい形式でないデータは保存を拒否 |
| データ量の上限 | 1人あたり最大500件、タイトル200字、メモ1000字まで |

### 5-4. 入力データの検証
タスクデータは「URL」「Firebase」「端末内保存」の3経路から読み込まれます。いずれも第三者が中身を差し替えられる可能性があるため、**画面に表示する前に必ず検証**しています。想定外の項目・不正な形式・過大なデータは、表示前に除去または安全な値へ置き換えられます。

これにより、細工したURLを踏ませて不正なスクリプトを実行させる攻撃（クロスサイトスクリプティング）を防いでいます。

### 5-5. リスク一覧

| リスク | レベル | 条件 | 対策 |
|---|---|---|---|
| URLを知られてデータを改ざんされる | 中 | URLを他人に教えた場合 | URLを教えない運用ルールの徹底 |
| 外部サーバー（Google）へのデータ送信 | 低 | アプリ使用中は常時 | 学校のICTポリシー確認 |
| 共有端末での閲覧 | 低〜中 | 端末を他者と共有する場合 | 1人1台端末なら問題なし |
| IDの推測によるアクセス | 非常に低 | 16文字ランダムのため現実的でない | 対策済み |
| 不正なURLによるスクリプト実行 | 非常に低 | — | 対策済み（5-4の入力検証） |
| 機械的な大量書き込みによる停止 | 低 | 悪意ある第三者が意図的に行った場合 | 対策済み（5-3のデータ量上限）。詳細は8章 |

## 8. 制限事項・既知の仕様

- タスクデータは**URLを失うと復元できない**（URLのブックマーク推奨）
- 設定（準備日数・言語）は**端末ごとに保存**される（他端末には同期されない）
- ブラウザのデータ削除を行うと**ローカルデータが消える**（Firebaseのデータは残る）
- 同じURLを複数端末で同時編集した場合、**最後に保存した内容が反映**される
- タスクは**1人あたり500件まで**（タイトル200字・メモ1000字まで）
- **クラウド同期を利用者側で無効にする設定はありません**（常時有効）
- 削除したタスクをあとから復元する機能はありません

## 9. 費用・可用性・保証について

### 9-1. 費用

本アプリはFirebaseの無料プラン（Spark）で運用しています。課金経路が存在しないため、**利用校・利用者に費用が発生することはありません。** アプリ内に広告はなく、有料機能もありません。

### 9-2. 無料枠は全利用者で共有します

重要な点として、**本アプリを使うすべての学校・生徒が、ひとつのデータベースの無料枠（保存1GB／月間転送10GB）を共有します。**

利用が広がった場合、次のことが起こり得ます。

- 無料枠に達した時点で、クラウド同期が一時的に停止する
- 停止中も各端末内のデータで通常どおり使える（タスクが消えるわけではない）
- 端末間の同期のみが止まる

1人あたりのデータ量に上限（500件・タイトル200字・メモ1000字）を設けていますが、利用規模によっては枯渇する可能性を排除できません。

### 9-3. 悪意ある大量書き込みへの備え

第三者が機械的に大量のデータを書き込み、無料枠を消費させる可能性があります。対策として5-3のデータ量上限を設けているほか、必要に応じてApp Check（自動化されたアクセスを遮断する仕組み）を有効化します。App Checkは生徒側の操作を一切変えずに導入できます。

### 9-4. 無保証

本アプリは個人が副業として無償で提供しているものです。以下をご了承のうえご利用ください。

- **現状有姿での提供**であり、動作およびデータの保全を保証しません
- 予告なく**仕様の変更・サービスの停止**を行う場合があります
- **個別のデータ復元・削除の依頼には応じられません**
- 本アプリの利用により生じた損害について、**責任を負いかねます**
- クラウド同期を利用者側で無効化する設定は提供していません

学校のICTポリシーで外部クラウドサービスの利用が認められない場合は、**本アプリの導入を見送ってください。**

成績・出欠・個人情報など、**学校の正式な記録の管理には使用しないでください。** 本アプリは生徒個人の予定管理を想定しています。
